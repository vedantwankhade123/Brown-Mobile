# Brown AI Mobile v1.0.3

## Changes
- Refined chat, sidebar, settings, and model store layouts with consistent dark controls.
- Added screen transitions and backgrounds that match the system bars.
- Simplified startup to one native splash screen and removed onboarding narration.
- Added real file selection, supported text-file reading, and cancellable file confirmations.
- Added device folder selection and cancellable confirmations for storage locations.
- Improved QR pairing access, model selection, notifications, storage, and download handling.
- Updated the README to use the white Brown logo.

## Download
Install Brown-AI-Mobile.apk on Android 10 or newer (ARM64).

## Validation
Local release build, TypeScript checks, 21 mobile suite checks, 9 picker checks, and 3 transition checks.
APK signature verified against the prior local release certificate.

## Current file support
Text, code, CSV, and JSON files can be added to the chat draft. PDF, Office, image, and audio file processing is not available yet.
