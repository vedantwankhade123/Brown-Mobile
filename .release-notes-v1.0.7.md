# Brown AI Mobile v1.0.7

- Recover queued model downloads with clearer waiting states, bounded direct-transfer fallback, background transfer support, safe retry and completed-file validation.
- Refine model cards, download progress, model activation and chat presentation.
- Improve History search, chat options, rename/delete dialogs and Downloads placement.
- Refine Connect layout and pairing controls.
- Increase Android versionCode to 19 so existing v1.0.6 installations can upgrade. Preserve the existing application ID and production signing certificate.

## Release assets

- Brown-AI-Mobile.apk: stable website download.
- Brown-AI-Mobile-v1.0.7.apk: versioned download, identical to the stable asset.
- SHA256SUMS.txt and release-manifest.json: integrity and package metadata.

The in-app updater reads the public GitHub release and its APK assets. Android asks for installation approval; allow Brown to install unknown apps if prompted. Chats, models and settings are retained during an in-place upgrade. No separate latest.yml is required for Android.
