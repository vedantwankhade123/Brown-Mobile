# Brown AI Mobile v1.0.2

### What's New

A full pass on the phone app: it now looks and feels like the desktop assistant, and updates itself from GitHub Releases.

#### New
- **ChatGPT-style chat screen** with a header model picker, so you can switch between installed models without digging through settings.
- **In-app updates** — the app checks the Brown-Mobile releases, downloads the new APK, and hands it to Android's installer. Update notifications arrive as a system notification when a release is waiting.
- **Production signing** — this build is signed with the release key, so in-place upgrades work from here on.

#### Improved
- New Brown brand marks, an animated splash screen, and an animated logo on the chat welcome card.
- The app now always opens on a fresh chat; History and Installed Models got proper empty states.
- Drawer rework: stacked history cards, quick-action cards, a "Connect to PC" entry, and a close button with smooth open/close animation.
- Keyboard no longer jumps the layout — the composer centers as it appears, and bottom panels respect the navigation bar.
- Voice replies use Kokoro only (browser speech removed) and add two male voices.
- PC pairing hardened: real QR codes, 120-second codes that regenerate, port fallback, and honest error messages instead of a fake success toast.
